# Hello Flutter: Tip Calculator

**Laboratory Exercise 018 – Flutter**

## Overview
This project is a simple Tip Calculator application developed using Flutter and Dart.

It allows users to enter a bill amount, select a tip percentage, and automatically calculate the tip and total amount.

## Features
- Enter a bill amount.
- Select a tip percentage (10%, 15%, or 20%).
- Automatically calculate the tip.
- Automatically calculate the total bill.
- Validate invalid or empty inputs.
- Display amounts with two decimal places.
- Material 3 theme.

## Technologies Used
- Flutter
- Dart
- Material Design 3
